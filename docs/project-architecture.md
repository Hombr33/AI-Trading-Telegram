# Project Architecture

This document describes the architecture of the Automated Forex & Crypto Trading Bot.

## Principles
- Modular design
- Separation of concerns
- Clear interfaces between modules

## Main Components
- AI Analysis Engine
- Market Data Collector
- Trade Executor
- Risk & Trade Management
- Telegram Bridge
- Scheduler & Automation
- Logging & Monitoring

## Extensibility
- New modules must not break existing functionality
- Use configuration files for new integrations
